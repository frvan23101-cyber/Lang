실행 방법

Python 3.10 이상 및 인터넷 접속이 필요합니다. 원문 캡처와 기사 선정표는 ZIP에 포함되어 있습니다.

1. ZIP 압축 해제
2. python -m pip install "spacy==3.8.18"
3. python -m spacy download en_core_web_sm
4. python -m spacy download fr_core_news_sm
5. python -m spacy download de_core_news_sm
6. python culinary_lexical_study/stage10/run_complete.py

Colab에서는 ZIP을 파일 패널로 업로드하고 !unzip -q nlp_full_reproduction_no_comments.zip 실행 후 위의 설치 및 실행 명령에 !를 붙여 실행할 수 있습니다.

**코드 정리과 재체계화는 LLM의 도움을 받았음을 알립니다.**
